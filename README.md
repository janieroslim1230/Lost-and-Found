# Lost and Found System

This project is to help people find their lost item or help report lost item on a platform.

## Problem statement
To people who often lost or misplaces item in public places, this project could help them retrieve back their items. To people who found valuable items and want to help get it back it its owner, this project could offer a quick solution to them.
